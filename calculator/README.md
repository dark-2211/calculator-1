# Desk Calculator

Extract the ZIP and open `index.html` in a browser. It runs offline, and no installation is needed.

- Type digits, a decimal point, or `+`, `-`, `*`, and `/`, or use the on-screen buttons.
- Press Enter or `=` to calculate, Backspace to delete, and Escape, Delete, or C to clear.
- Try `2 + 3 * 4` for `14`, `0.1 + 0.2` for `0.3`, and `8 / 0` for a divide-by-zero message.
- To enter a standalone negative number, start with `0 -` and then enter the number.

## What to study

- **Functions and operators** in `script.js`: `evaluate()` applies standard arithmetic precedence without using `eval()`.
- **Events** in `script.js`: the click and keydown listeners both call `handleKey()`.
- **DOM manipulation** in `script.js`: `render()` updates the display, and `flash()` adds temporary button feedback.
- **Responsive layout** in `style.css`: CSS Grid, flexible sizes, and media queries keep the keypad usable across screen sizes.

Reference: [MDN JavaScript Functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions)
